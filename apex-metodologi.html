Problem Statement

Anak-anak Indonesia tidak lagi bersaing hanya dengan teman sekelas — mereka bersaing dengan talenta dari Singapura, Finlandia, dan Silicon Valley. Sistem pendidikan tradisional yang berbasis hafalan dan nilai ujian gagal membekali mereka dengan kemampuan Abad 21.

Masalah yang dipecahkan

  • Belajar pasif (menonton video satu arah)
  • Tidak ada personalisasi per tingkat kemampuan
  • Orang tua tidak memiliki visibilitas perkembangan
  • Hafalan tanpa pemahaman mendalam
  • Tidak ada integrasi nilai dan karakter

Solusi APEX

  • AI Socratic Tutor — tanya balik, tidak beri jawaban
  • Mastery gating — lanjut jika sudah ≥80% paham
  • Parent dashboard dengan radar 6 dimensi holistik
  • Spaced Repetition (SM-2) untuk retensi jangka panjang
  • Integrasi ibadah, niat, dan syukur (Pilar 7)

7 Pilar Metodologi — Inti Logika Platform

Setiap fitur dalam platform harus dapat dilacak ke salah satu dari 7 pilar ini. Developer HARUS memahami pilar mana yang diimplementasikan oleh setiap komponen UI dan backend service.

PILAR 01
Metacognition First
Sebelum dan sesudah belajar, siswa mengisi jurnal mini. Sistem memantau apakah rasa percaya diri sesuai dengan hasil tes aktual.
→ WeeklyReflection, Pre/Post Journal di AIClassroom
PILAR 02
Inquiry-Based Learning
AI Socrates TIDAK boleh memberi jawaban langsung. Wajib merespons dengan guiding question yang memancing siswa berpikir sendiri.
→ AIClassroom + System Prompt Socrates
PILAR 03
Spaced Repetition
Algoritma SuperMemo-2 (SM-2) menjadwalkan ulang review flashcard berdasarkan kualitas ingatan (0–5). Interval: hari ke-1 → 6 → interval × E-Factor.
→ SpacedRepetition, IslamicHub (Muraja'ah)
PILAR 04
Mastery Learning
Gerbang materi terkunci sampai siswa mencapai 80% mastery. Jika gagal, sistem menyajikan materi penunjang yang berbeda — bukan soal yang sama.
→ LearningHub mastery gate, MockExam
PILAR 05
Project-Based Learning
Di akhir semester, siswa mengunggah hasil karya nyata (website, pitch deck, lab report) yang menjadi bukti kemampuan untuk mendaftar universitas.
→ Portfolio, MentorPortal (IB HOTS Rubric)
PILAR 06
Bilingual Academic Output
Proyek, esai, dan presentasi di level SMP ke atas harus dikerjakan dalam dua bahasa (Indonesia + Inggris). Ini syarat mutlak untuk daya saing global.
→ Portfolio bilingual flag, LanguageToggle
PILAR 07
Tafakkur & Akhlaq Integration — Islamic Worldview
Pendidikan global tanpa akar moral hanya menghasilkan generasi cerdas yang kehilangan arah. "Adab sebelum ilmu." Ilmu sains diarahkan ke Tafakkur (merenungi ciptaan Allah). Ambisi global diikat dengan Akhlakul Karimah. BUKAN sekadar add-on — ini adalah worldview yang memframing seluruh kurikulum.
→ IslamicHub: Smart Muraja'ah + Tafakkur Checkpoint + Mutaba'ah Yaumiyyah + Jurnal Syukur

Logika Inti AI Socrates — Aturan Mutlak

Ini bukan sekadar prompt biasa. Ini adalah perilaku sistem yang wajib diimplementasikan dan ditest secara eksplisit oleh developer.

Aturan yang TIDAK BOLEH dilanggar

SkenarioRespons yang SALAHRespons yang BENAR

SM-2 Algorithm — Formula Wajib Diimplementasikan Persis

Rumus E-Factor update setelah setiap review:

EF' = EF + (0.1 − (5−q) × (0.08 + (5−q) × 0.02))
  • Minimum EF = 1.3 (jangan pernah di bawah ini)
  • Jika quality < 3 → reset interval ke 1, repetitions ke 0
  • Repetisi ke-1 → interval 1 hari | Ke-2 → 6 hari | Ke-3+ → interval × EF
  • q = 0 (lupa total) sampai 5 (ingat sempurna tanpa ragu)

User Stories — Format Standar Developer

Setiap story memiliki: Who (siapa), What (apa yang dilakukan), Why (tujuan), dan Acceptance Criteria yang dapat ditest.

Siswa (Student)

STORY S-01 · Spaced Repetition · P1 Dev
Sebagai siswa, saya ingin melihat flashcard yang harus saya review hari ini berdasarkan algoritma SM-2, agar ingatan saya diperkuat secara efisien tanpa membuang waktu review materi yang sudah kuat.
✓ AC: Sistem menampilkan hanya kartu dengan nextReviewAt ≤ today · Setelah rating, interval kartu diperbarui sesuai SM-2 · Kartu yang dinilai q<3 muncul kembali besok
STORY S-02 · AI Socrates · P1 Dev
Sebagai siswa, saya ingin bertanya ke AI tentang materi yang sulit, agar AI membantu saya menemukan jawaban sendiri lewat pertanyaan pancingan — bukan langsung memberi jawaban.
✓ AC: AI tidak pernah menjawab soal langsung · Selalu merespons dengan ≥1 guiding question · Jika siswa salah 3× berturut-turut → tampilkan hint (bukan jawaban) · Loading state: "Socrates sedang memikirkan petunjuk terbaik untukmu..."
STORY S-03 · Mastery Gate · P1 Dev
Sebagai siswa, saya ingin bab berikutnya terkunci sampai saya mencapai 80% mastery di bab ini, agar fondasi ilmu saya solid sebelum maju ke materi lebih sulit.
✓ AC: Progress bar menampilkan persentase mastery · Tombol "Lanjut" disabled jika <80% · Di bawah 80%: tampilkan copy "Hampir Sampai! Usahamu sudah X%, mari kita perkuat Y% sisanya 💪" · Di atas 80%: copy "Luar Biasa! Materi ini sudah kamu kuasai! 🌟"
STORY S-04 · Islamic Hub · P1 Dev
Sebagai siswa Muslim, saya ingin mengisi niat belajar sebelum memulai sesi dan jurnal syukur setelah selesai, agar belajar saya bernilai ibadah dan tidak hanya mengejar nilai.
✓ AC: Niat Check muncul sebagai modal 3-langkah sebelum sesi · Tidak bisa skip kecuali sudah jawab ketiga pertanyaan · Jurnal syukur di akhir sesi +20 Charity Points · Mutaba'ah tracker mencatat ibadah harian dengan streak counter
STORY S-05 · Weekly Reflection · P2 Dev
Sebagai siswa, saya ingin mengisi refleksi mingguan (3 pertanyaan + confidence slider 1–10), agar saya membangun kesadaran tentang apa yang sudah dan belum dipahami (metacognition).
✓ AC: Refleksi dapat diisi sekali per minggu · Week navigator untuk melihat refleksi masa lalu · Simpan +50 Charity Points · Confidence slider 1–10 tersimpan ke database

Orang Tua (Parent)

STORY P-01 · Radar Chart · P1 Design
Sebagai orang tua, saya ingin melihat grafik radar 6 dimensi (Kognitif, Bahasa, Digital, Karakter, Spiritual, Leadership), agar saya bisa melihat sekilas keseimbangan tumbuh kembang anak — bukan hanya nilai akademis.
✓ AC: Radar SVG interaktif dengan 6 sumbu · Hover pada titik menampilkan tooltip detail · Alert otomatis jika ada dimensi <70% · Bahasa profesional: "Insight: [nama] terlihat butuh waktu lebih lama di..."
STORY P-02 · Smart Alert · P1 Dev
Sebagai orang tua, saya ingin menerima notifikasi cerdas jika sistem mendeteksi anomali pada pola belajar atau ibadah anak, agar saya bisa intervensi dengan cara yang tepat dan tidak menghakimi.
✓ AC: Alert muncul jika: mastery <60% selama 3 hari berturut-turut, ibadah tracker kosong 3+ hari, tidak ada sesi belajar 2+ hari berturut-turut · Copy alert menggunakan bahasa empatik, bukan menghakimi · Alert bisa di-dismiss

Mentor

STORY M-01 · IB Rubric · P2 Dev
Sebagai mentor, saya ingin menilai portofolio siswa menggunakan rubrik IB HOTS 4 level (Beginner → Mastery), agar penilaian saya konsisten, terstandar, dan dapat dibandingkan antar siswa.
✓ AC: 4 kriteria × 4 level = 16 skor yang harus diisi · Jika rata-rata ≥3, badge digital otomatis diterbitkan · Feedback bisa dalam bentuk teks atau simulasi voice note · Skor tersimpan ke database sebagai bagian dari assessment holistik

Acceptance Criteria — Definition of Done

Sebuah fitur dianggap "done" hanya jika semua AC berikut terpenuhi. QA engineer dan developer HARUS mencentang setiap item sebelum merge ke main branch.

AC Global — Berlaku untuk Semua Fitur

  • Semua operasi DB diproteksi: user hanya bisa baca/tulis data miliknya sendiri (WHERE userId = session.user.id)
  • Error state ditangani: jika API call gagal, tampilkan pesan error yang ramah — bukan raw error message
  • Loading state tersedia untuk semua async operations
  • Responsive: berfungsi di viewport 375px (mobile) dan 1440px (desktop)
  • Bilingual: semua teks punya versi Bahasa Indonesia dan Inggris
  • Microcopy HARUS menggunakan kalimat dari Panduan UX APEX — tidak boleh improvisasi
  • Warna CTA: primary = Cyan #06B6D4, error/warning = Coral #F97316, success = Emerald #10B981

AC per Fitur Kritis

P1 AI Socrates — Acceptance Criteria
  • Test: kirim "Berapa jawaban soal no. 3?" → AI HARUS merespons dengan pertanyaan balik (bukan jawaban)
  • Test: kirim jawaban salah 3× berturut-turut → AI HARUS memberikan hint di pesan ke-4
  • Test: loading state menampilkan "Socrates sedang memikirkan petunjuk terbaik untukmu... 💭"
  • Test: API call ke Anthropic diproxy melalui server — API key TIDAK boleh exposed ke client-side
  • Test: conversation history dikirim setiap request (bukan hanya pesan terakhir)
  • Test: system prompt Socrates ter-inject di setiap request (tidak bisa dioverride user)
P1 SM-2 Algorithm — Acceptance Criteria
  • Test: kartu dengan quality=5, EF=2.5, repetitions=0 → nextInterval=1, newEF=2.6
  • Test: kartu dengan quality=2 (salah) → nextInterval=1, repetitions=0 (reset)
  • Test: kartu dengan quality=4, EF=2.5, repetitions=2, interval=6 → nextInterval=15, newEF=2.5
  • Test: EF tidak pernah di bawah 1.3
  • Test: kartu due tampil di queue (nextReviewAt ≤ today) · kartu belum due tidak tampil
  • Test: setelah rating, data tersimpan ke DB dan kartu hilang dari queue hari ini
P1 Mastery Gate — Acceptance Criteria
  • Test: mastery 79% → tombol "Lanjut" disabled · copy: "Hampir Sampai! Usahamu sudah 79%..."
  • Test: mastery 80% → tombol "Lanjut" enabled · copy: "Luar Biasa! Materi ini sudah kamu kuasai! 🌟"
  • Test: progress bar marker 80% visible di UI sebagai visual reference
  • Test: bar warna coral jika <80%, hijau jika ≥80%
  • Test: mastery tersimpan ke DB setelah setiap quiz session
P1 Security — Acceptance Criteria
  • Test: akses /api/* tanpa session → return 401 Unauthorized
  • Test: user A tidak bisa baca/tulis data user B (test dengan dua akun berbeda)
  • Test: ANTHROPIC_API_KEY tidak muncul di network tab browser (harus server-side only)
  • Test: DATABASE_URL tidak muncul di client-side JavaScript
  • Test: .env.local tidak ter-commit ke Git (cek dengan git log)
  • Test: password user di-hash dengan bcrypt (bukan plaintext di DB)
P2 Parent Smart Alert — Trigger Conditions
  • Alert "Insight": dimensi radar manapun <70% selama 3+ hari berturut-turut
  • Alert "Spiritual": ibadah tracker kosong 3+ hari (tidak ada IbadahLog dalam 3 hari)
  • Alert "Tidak Aktif": tidak ada QuizSession atau BrainDump 2+ hari berturut-turut
  • Alert "Pencapaian": masteryPct naik ≥15 poin dalam satu minggu → kirim ke Parent
  • Copy alert HARUS menggunakan bahasa empatik dari Panduan UX, bukan raw data
