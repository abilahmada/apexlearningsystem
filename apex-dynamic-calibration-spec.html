APEX // DYNAMIC CALIBRATION SPEC

Dynamic Calibration Algorithm — Spesifikasi Teknis Lengkap

Background service yang berjalan 14 hari pasca intake assessment. Mengumpulkan 3 sinyal dari aktivitas nyata siswa, menggabungkan dengan weighted formula, menghasilkan placement lebih akurat dari intake saja.

Alur data tingkat tinggi

// Event flow: aktivitas siswa → placement final

UserActivity (quiz, flashcard, session, chat)
  → EventStream (Redis Streams)
    → SignalCollectors (3 parallel workers)
      → CalibrationSignal table (raw signals per day)
        → NightlyCronJob (aggregate + normalize)
          → RunningTheta table (per-dimension estimates)
            → Day14CronJob (weighted combine + CI check)
              → FlagEngine (anomaly detection)
                → [ManualReview → Mentor] OR [AutoLock]
                  → CompetencyProfile (final placement)
                    → Notification (student + parent)

Signal Collectors — 3 Implementasi Detail

Collector 1 — Mastery velocity

Mengukur kecepatan siswa mencapai 80% mastery per modul dibanding cohort normative. Direkam setiap kali siswa melewati threshold mastery. Mengukur learning rate, bukan pengetahuan awal.

// lib/calibration/mastery-velocity-collector.ts

interface MasteryEvent {
  userId:       string
  subject:      string
  moduleId:     string
  masteryPct:   number
  sessionCount: number   // berapa sesi untuk capai ini
  daysElapsed:  number   // hari sejak modul pertama dibuka
  timestamp:    Date
}

export async function collectMasteryVelocity(event: MasteryEvent) {
  if (event.masteryPct < 80) return  // hanya rekam saat threshold tercapai

  const cohortMedian = await getCohortMedianDays({
    subject:    event.subject,
    gradeLevel: await getUserGrade(event.userId),
  })

  // velocity = median / actual (>1 lebih cepat, <1 lebih lambat)
  const rawVelocity     = cohortMedian / Math.max(event.daysElapsed, 0.5)
  const clampedVelocity = Math.min(Math.max(rawVelocity, 0.1), 3.0)

  await prisma.calibrationSignal.create({
    data: {
      userId:     event.userId,
      signalType: 'mastery_velocity',
      dimension:  subjectToDimension(event.subject),
      rawValue:   clampedVelocity,
      metadata:   { moduleId: event.moduleId, cohortMedian, daysElapsed: event.daysElapsed },
      recordedAt: event.timestamp,
    }
  })
}

Collector 2 — Error pattern analyzer

Menganalisis pola kesalahan per tag konsep. Lebih diagnostik dari skor total karena mengidentifikasi gap konseptual yang spesifik — bukan hanya berapa banyak yang salah, tapi di mana yang salah.

// lib/calibration/error-pattern-collector.ts

export async function collectErrorPattern(userId: string, dimension: string) {
  const answers = await prisma.quizAnswer.findMany({
    where: {
      session: { userId, subject: dimensionToSubjects(dimension) },
      createdAt: { gte: daysAgo(14) }
    },
    include: { question: { select: { conceptTags: true, difficulty: true } } }
  })

  // group errors by concept tag
  const tagStats: Record<string, { total: number; wrong: number }> = {}

  for (const a of answers) {
    for (const tag of a.question.conceptTags) {
      if (!tagStats[tag]) tagStats[tag] = { total: 0, wrong: 0 }
      tagStats[tag].total++
      if (!a.isCorrect) tagStats[tag].wrong++
    }
  }

  // systematic error: >60% salah di satu tag, minimal 3 soal
  const systematicGaps = Object.entries(tagStats)
    .filter(([_, s]) => s.total >= 3 && s.wrong / s.total > 0.60)
    .map(([tag, s]) => ({ tag, errorRate: s.wrong / s.total }))

  const systematicRate = answers.length > 0
    ? systematicGaps.reduce((s, g) => s + tagStats[g.tag].wrong, 0) / answers.length
    : 0

  // error pattern score: 5.0 = no gaps, 1.0 = severe gaps
  const errorPatternScore = Math.max(1.0, 5.0 - systematicRate * 4.0)

  await prisma.calibrationSignal.create({
    data: {
      userId, signalType: 'error_pattern', dimension,
      rawValue: errorPatternScore,
      metadata: { systematicGaps, totalAnswers: answers.length },
      recordedAt: new Date(),
    }
  })

  // queue remediation jika ada systematic gaps
  if (systematicGaps.length > 0) {
    await queueRemediationModules(userId, dimension, systematicGaps)
  }
}

Collector 3 — Engagement signal

// lib/calibration/engagement-collector.ts

export async function collectEngagementSignal(userId: string) {
  const [sessions, rereads, skips, extras, drops] = await Promise.all([
    getSessionCount(userId, 14),
    getRereadRate(userId, 14),       // pct konten dibuka ulang
    getSkipRate(userId, 14),
    getVoluntaryExtras(userId, 14),
    getDropoutRate(userId, 14),
  ])

  // engagement score 1–10, bukan sinyal placement langsung
  // digunakan sebagai CI multiplier
  const score =
      2.0 * Math.min(sessions / 10, 1)     // sesi: max 2 pts
    + 2.0 * (1 - drops)                      // retention: max 2 pts
    + 2.0 * (1 - Math.min(skips, 1))        // non-skip: max 2 pts
    + 2.0 * Math.min(extras / 3, 1)         // extras: max 2 pts
    + 2.0 * (1 - Math.min(rereads * 2, 1)) // low reread: max 2 pts

  await prisma.calibrationSignal.create({
    data: {
      userId, signalType: 'engagement', dimension: 'global',
      rawValue:   Math.min(Math.max(score, 1), 10),
      metadata:   { sessions, rereads, skips, extras, drops },
      recordedAt: new Date(),
    }
  })
}

Formula Engine — Normalisasi + Weighted Combination

Step 1 — Normalisasi raw signals ke skala 1–10

VelocityNorm(v) = clamp( tanh(v − 1.0) × 3.0 + 5.0, 1, 10 )
v=1.0 (rata-rata) → 5.0 · v=1.5 → ~6.8 · v=0.5 → ~3.2

ErrorNorm(e) = 5.0 − (systematic_error_rate × 4.0)
e=0% systematic → 5.0 · e=50% → 3.0 · e=100% → 1.0

ParentNorm(p, θ) = θ × (1 + p × 0.15)   [p ∈ {−2 … +2}]
Adjustment +2 menaikkan theta ~30%, −2 menurunkan ~30%

CI_final(d) = CI_intake × (1 − CoverageScore × EngagementMultiplier)
CoverageScore = min(sessions/10, 1.0) · EngMult = 0.7 + (eng/10)×0.3

Step 2 — Bobot per dimensi

Dimensiw₁ intakew₂ velocityw₃ errorw₄ parentRationale
Kognitif0.350.350.200.10Data platform sangat valid untuk kognitif.
Bahasa0.300.250.300.15Error pattern penting untuk skill bahasa.
Digital / CS0.400.350.150.10CAT + velocity sangat akurat untuk CS.
Karakter0.200.200.150.45Platform kurang bisa ukur karakter. Parent dominan.
Spiritual0.100.100.100.70Ibadah hanya bisa dinilai orang tua.
Leadership0.250.200.200.35Oral assessment + parent sama pentingnya.

// lib/calibration/placement-calculator.ts

const WEIGHTS = {
  kognitif:   { w1: .35, w2: .35, w3: .20, w4: .10 },
  bahasa:     { w1: .30, w2: .25, w3: .30, w4: .15 },
  digital:    { w1: .40, w2: .35, w3: .15, w4: .10 },
  karakter:   { w1: .20, w2: .20, w3: .15, w4: .45 },
  spiritual:  { w1: .10, w2: .10, w3: .10, w4: .70 },
  leadership: { w1: .25, w2: .20, w3: .20, w4: .35 },
} as const

const clamp = (v: number, mn: number, mx: number) => Math.min(Math.max(v,mn),mx)

export function normalizeVelocity(v: number) {
  return clamp(Math.tanh(v - 1.0) * 3.0 + 5.0, 1, 10)
}
export function normalizeError(systematicRate: number) {
  return clamp(5.0 - systematicRate * 4.0, 1, 10)
}
export function normalizeParent(theta: number, adj: number) {
  return clamp(theta * (1 + adj * 0.15), 1, 10)
}
export function calcCI(sessions: number, engagement: number, intakeCI = 2.4) {
  const coverage = Math.min(sessions / 10, 1.0)
  const engMult  = 0.7 + (engagement / 10) * 0.3
  return intakeCI * (1 - coverage * engMult)
}

export async function calculateFinalPlacement(userId: string): Promise<PlacementResult> {
  const [session, signals, parentInput, engagement] = await Promise.all([
    getAssessmentSession(userId),
    getAggregatedSignals(userId),
    getParentValidation(userId),
    getEngagementScore(userId),
  ])

  if (session.sessionsCompleted < 5)
    return { status: 'insufficient_data', action: 'extend_window' }

  const results = Object.entries(WEIGHTS).map(([dim, w]) => {
    const intake  = session.intakeTheta[dim] ?? 5.0
    const velNorm = normalizeVelocity(signals[dim]?.velocity ?? 1.0)
    const errNorm = normalizeError(signals[dim]?.systematicRate ?? 0)
    const parNorm = parentInput
      ? normalizeParent(intake, parentInput.adjustments[dim] ?? 0)
      : intake

    const finalTheta = clamp(
      w.w1*intake + w.w2*velNorm + w.w3*errNorm + w.w4*parNorm, 1, 10
    )
    // safety: jangan turun lebih dari 2 poin dari intake
    const safeTheta = Math.max(finalTheta, intake - 2.0)
    const ci        = calcCI(session.sessionsCompleted, engagement)
    const delta     = Math.abs(safeTheta - intake)

    return { dim, finalTheta: safeTheta, ci, delta, intake, velNorm, errNorm, parNorm }
  })

  const flags       = detectFlags(results, session, parentInput)
  const needsReview = flags.some(f => ['mismatch','parent_disagreement'].includes(f.type))

  return {
    status:  needsReview ? 'pending_review' : 'ready_to_lock',
    dimensions: results,
    flags,
    canLock: !needsReview && results.every(r => r.ci < 0.8),
  }
}

// Helper: konversi theta ke level
export function thetaToLevel(theta: number): CompetencyLevel {
  if (theta < 4)  return 'DEVELOPING'
  if (theta < 6)  return 'SOLID'
  if (theta < 8)  return 'PROFICIENT'
  return          'ADVANCED'
}

// app/api/cron/nightly-calibration/route.ts

export async function GET(req: Request) {
  if (req.headers.get('authorization') !== `Bearer ${process.env.CRON_SECRET}`)
    return new Response('Unauthorized', { status: 401 })

  const activeSessions = await prisma.assessmentSession.findMany({
    where: {
      status: 'CALIBRATING',
      calibrationEndsAt: { gte: new Date() }
    }
  })

  const results = await Promise.allSettled(
    activeSessions.map(s => processNightlySignals(s.userId))
  )

  const failed = results.filter(r => r.status === 'rejected')
  if (failed.length) logError('nightly-calibration', failed)

  return Response.json({
    processed: activeSessions.length,
    failed:    failed.length,
    ts:        new Date().toISOString()
  })
}

async function processNightlySignals(userId: string) {
  await Promise.all([
    collectMasteryVelocityBatch(userId),
    collectErrorPatternBatch(userId),
    collectEngagementSignal(userId),
  ])

  await updateRunningTheta(userId)

  const session = await getAssessmentSession(userId)
  const days    = daysBetween(session.startedAt, new Date())

  if (days === 7) await checkEarlyIntervention(userId, session)

  await prisma.assessmentSession.update({
    where: { userId },
    data:  { sessionsCompleted: { increment: 1 } }
  })
}

Placement lock job

// app/api/cron/placement-lock/route.ts

async function lockExpiredSessions() {
  const expired = await prisma.assessmentSession.findMany({
    where: { status: 'CALIBRATING', calibrationEndsAt: { lt: new Date() } }
  })

  for (const session of expired) {
    const result = await calculateFinalPlacement(session.userId)

    switch (result.status) {
      case 'insufficient_data':
        if (session.extensionCount < 2) {
          await prisma.assessmentSession.update({
            where: { id: session.id },
            data: {
              calibrationEndsAt: addDays(new Date(), 7),
              extensionCount:    { increment: 1 },
              status:            'EXTENDED'
            }
          })
          await notifyParentLowEngagement(session.userId)
        } else {
          await forceLockWithIntakeOnly(session.userId)
        }
        break

      case 'pending_review':
        await assignToMentorQueue(session.userId, result.flags)
        break

      case 'ready_to_lock':
        await lockPlacement(session.userId, result.dimensions)
        await notifyPlacementFinal(session.userId, result.dimensions)
        break
    }
  }
}

async function lockPlacement(userId: string, dims: DimensionResult[]) {
  // atomic: semua dimensi tersimpan atau tidak sama sekali
  await prisma.$transaction(async (tx) => {
    for (const d of dims) {
      await tx.competencyProfile.upsert({
        where:  { userId_dimension: { userId, dimension: d.dim } },
        update: { theta: d.finalTheta, ci: d.ci, source: 'CALIBRATION',
                  level: thetaToLevel(d.finalTheta), lockedAt: new Date() },
        create: { userId, dimension: d.dim, theta: d.finalTheta, ci: d.ci,
                  level: thetaToLevel(d.finalTheta), source: 'CALIBRATION',
                  lockedAt: new Date() }
      })
    }
    await tx.assessmentSession.update({
      where: { userId },
      data:  { status: 'PLACED', placementLockedAt: new Date(),
               finalTheta: Object.fromEntries(dims.map(d => [d.dim, d.finalTheta])) }
    })
  })
}

Safety constraints — checklist wajib sebelum go-live

  • ! Placement tidak boleh turun lebih dari 2 poin theta dalam satu kalibasi
  • ! Angka theta mentah tidak boleh ditampilkan ke siswa atau orang tua — hanya level deskriptif
  • ! Jangan gunakan sinyal jika sessions < 3 — sample size terlalu kecil
  • ! lockPlacement harus dalam satu Prisma transaction — atomic atau rollback
  • ! Jika parent_disagreement flag aktif, jangan lock tanpa mentor resolution
  • ! Cron job harus idempotent — double-run tidak boleh menghasilkan state berbeda
